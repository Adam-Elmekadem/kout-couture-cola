# Couture-Cola

An independent streetwear concept in the Kout Project portfolio. Familiar pop energy is rebuilt as collectible outerwear, fleece, and utility cuts. The page is a working design demo with product filtering, product detail dialogs, size selection, and a local concept bag. It does not take orders or payments.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. `npm run check` checks TypeScript; `npm run build` produces the Next.js site.

## Files

- `BRAND_SYSTEM.md` — identity, color, type, photography, voice, and usage rules
- `IMAGE_PROMPTS.md` — campaign and product image directions
- `app/` — landing page and styling
- `lib/products.ts` — concept product catalog and pricing
- `public/images/` — optimized original concept imagery
- `public/cc-mark.svg` — original geometric monogram

This is independent speculative work, not an official collaboration with any beverage brand. The identity deliberately avoids existing script marks and trade dress. Seek trademark review before commercial use.
